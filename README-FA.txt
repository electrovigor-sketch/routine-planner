روتین | پلنر جامع زندگی و کسب‌وکار
=======================

این یک وب‌اپلیکیشن مستقل و محلی است؛ به حساب کاربری یا سرور پایگاه داده نیاز ندارد.
اطلاعات با localStorage مرورگر ذخیره می‌شود. داده‌ها بین کامپیوتر و موبایل همگام‌سازی نمی‌شوند و در هر مرورگر/دستگاه جدا هستند.

روش ۱ ـ اجرا روی کامپیوتر (ویندوز)
---------------------------------
۱. فایل ZIP را از حالت فشرده خارج کن.
۲. وارد پوشه routine_planner_crm شو.
۳. در نوار آدرس File Explorer بنویس cmd و Enter بزن تا ترمینال در همان پوشه باز شود.
۴. اگر Python نصب است، این دستور را اجرا کن:
   py -m http.server 8000
   اگر دستور py کار نکرد:
   python -m http.server 8000
۵. مرورگر را باز کن و برو به:
   http://localhost:8000
۶. برنامه باز می‌شود. از منوی «تنظیمات و پشتیبان‌گیری» یکی از چهار تم را انتخاب کن.

بخش‌های نسخه جامع: داشبورد، کارها، CRM و مشتریان، سفارش‌ها، حسابداری شخصی، حسابداری کسب‌وکار، اقساط و بدهی‌ها، محصولات و انبار، عادت‌ها، اهداف و گزارش‌ها، یادداشت‌ها. هر بخش تحلیلی نمودار و شاخص‌های متناسب با داده‌های ثبت‌شده دارد.

روش ۲ ـ اجرای ساده بدون نصب
---------------------------
می‌توانی index.html را دوبار کلیک کنی و باز کنی. بخش‌های اصلی معمولاً کار می‌کنند،
اما نصب به‌صورت اپلیکیشن، حالت آفلاین و service worker به اجرای محلی از طریق HTTP نیاز دارند.
برای تجربه کامل، روش ۱ را توصیه می‌کنیم.

استفاده روی موبایل
------------------
- برای نصب PWA و دسترسی پایدار، برنامه باید از یک نشانی HTTPS میزبانی شود یا روی localhost همان دستگاه اجرا شود.
- اگر فقط از طریق IP کامپیوتر در شبکه Wi-Fi وارد شوی، ممکن است خود برنامه باز شود؛ اما نصب PWA در مرورگر موبایل روی HTTP معمولاً مجاز نیست.
- می‌توانی این پوشه را روی یک سرویس میزبانی استاتیک HTTPS قرار بدهی. چون ذخیره‌سازی محلی است، داده‌های موبایل و کامپیوتر جدا خواهند بود.
- برای دیدن برنامه از موبایل و کامپیوتر با یک مجموعه اطلاعات مشترک، باید در آینده ذخیره‌سازی ابری/سرور اضافه شود؛ این نسخه چنین همگام‌سازی‌ای ندارد.

نصب روی کامپیوتر
----------------
بعد از اجرای برنامه از localhost، در مرورگرهای سازگار (مثل Chrome یا Edge) گزینه Install app / نصب برنامه
ممکن است در منوی مرورگر یا نوار آدرس ظاهر شود. در موبایل، پس از میزبانی HTTPS، از منوی مرورگر گزینه
Add to Home Screen / افزودن به صفحه اصلی را انتخاب کن.

امکانات فعلی
------------
- داشبورد و آمار پایه
- تسک‌ها، اولویت و تاریخ اختیاری
- دفتر مشتریان، شرکت، تلفن، یادداشت و مرحله ارتباط
- پیگیری مشتری با ساخت خودکار تسک
- سفارش‌ها، وضعیت و مجموع مبلغ
- یادداشت‌ها
- هدف و گزارش خلاصه
- چهار تم زیتونی، تیره، رز و آبی
- خروجی و بازیابی پشتیبان JSON
- ذخیره خودکار در مرورگر فعلی

پشتیبان‌گیری و حریم خصوصی
-------------------------
از بخش «اهداف و گزارش‌ها» یا «تنظیمات و تم» به‌طور منظم فایل پشتیبان JSON بگیر.
پاک‌کردن داده‌های مرورگر یا استفاده از حالت ناشناس ممکن است اطلاعات را حذف کند.
این برنامه برای ذخیره اطلاعات واقعی حساس مشتریان، بدون بررسی امنیتی و بکاپ منظم توصیه نمی‌شود.

یادداشت فنی
-----------
فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ اگر اینترنت در دسترس نباشد، فونت جایگزین استفاده می‌شود.
تمام داده‌های CRM در این نسخه روی سرور ارسال نمی‌شوند.


نسخه ارتقایافته: تم تیره به‌صورت پیش‌فرض فعال است. تاریخ کارها و تراکنش‌ها را می‌توان به شکل شمسی YYYY/MM/DD وارد کرد؛ نمونه ۱۴۰۵/۰۷/۱۹. در تراکنش‌ها دکمه ویرایش اضافه شده و حذف/ویرایش اثر مبلغ را در موجودی حساب اصلاح می‌کند.

نسخه اهداف پیشرفته
------------------
بخش «اهداف و گزارش‌ها» اکنون عنوان هدف، دسته‌بندی، اولویت، تاریخ شروع و مهلت شمسی، مقدار هدف و پیشرفت، واحد اندازه‌گیری، وضعیت، دلیل اهمیت و فهرست قدم‌های اجرایی را نگه می‌دارد. برای ثبت مرحله انجام‌شده، ابتدای خط آن [x] بنویسید؛ برای مرحله انجام‌نشده [ ].

مهم: این برنامه اطلاعات را فقط روی همان مرورگر/دستگاه نگه می‌دارد. پیش از جایگزینی نسخه سایت، از داخل برنامه فایل پشتیبان بگیرید. فایل پشتیبان را در مخزن عمومی GitHub قرار ندهید؛ ممکن است اطلاعات شخصی داشته باشد.


امکانات افزوده در این نسخه:
- تعریف چند کسب‌وکار مستقل و انتخاب کسب‌وکار فعال برای مشاهده داشبورد و گزارش همان کسب‌وکار.
- ثبت تراکنش‌های هر کسب‌وکار به صورت جداگانه.
- تعریف کارهای تکرارشونده روزانه، هفتگی و ماهانه؛ با انجام کار، نوبت بعدی ساخته می‌شود.
- نمایش سررسیدهای اقساط و بدهی‌های ثبت‌شده.
